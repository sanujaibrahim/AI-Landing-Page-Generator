# 🤖 AI Landing Page Generator

An AI-powered web application that generates modern and responsive landing pages from simple user prompts.

## 🚀 Project Overview

The AI Landing Page Generator allows users to describe the type of website they want, such as a fitness website, restaurant website, portfolio, or business website.

Based on the input, the application generates a structured landing page with HTML and styling.

## ✨ Features

* 🤖 AI-assisted landing page generation
* 🎨 Modern and responsive webpage design
* 📝 Generate websites from simple prompts
* 💻 HTML, CSS and JavaScript support
* ⚡ Simple and user-friendly interface
* 🌐 Preview generated landing pages

## 🛠️ Technologies Used

## ▶️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/yourusername/AI-Landing-Page-Generator.git
```

### 2. Open the project folder

```bash
cd AI-Landing-Page-Generator
```

### 3. Install the required packages

```bash
python -m pip install -r requirements.txt
```

### 4. Run the application

```bash
streamlit run app.py
```

The application will open in your browser.
